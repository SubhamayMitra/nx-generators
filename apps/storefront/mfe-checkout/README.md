# storefront-mfe-checkout

A Module Federation MFE generated by `nx g mfe`, scoped to `storefront-shell`, bundled with rspack.

## Standalone

`nx serve storefront-mfe-checkout` runs this MFE completely on its own — its own
router (`BrowserRouter` in `src/bootstrap.tsx`), its own Apollo Client
(`src/services/apollo-client.ts`). No shell required.

## Adding a feature

`nx g feature storefront-mfe-checkout <feature-name>` scaffolds into
`src/features/<feature-name>/` and registers a route in
`src/app/routes.tsx` — no bundler or shell config changes needed.
