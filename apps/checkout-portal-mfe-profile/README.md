# checkout-portal-mfe-profile

A Module Federation MFE generated by `nx g mfe`, scoped to `checkout-portal-shell`, bundled with rspack.

## Standalone

`nx serve checkout-portal-mfe-profile` runs this MFE completely on its own — its own
router (`BrowserRouter` in `src/bootstrap.tsx`), its own Apollo Client
(`src/services/apollo-client.ts`). No shell required.

## Adding a feature

`nx g feature checkout-portal-mfe-profile <feature-name>` scaffolds into
`src/features/<feature-name>/` and registers a route in
`src/app/routes.tsx` — no bundler or shell config changes needed.
