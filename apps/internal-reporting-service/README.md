# internal-reporting-service

A GraphQL microservice generated by `nx g graphql-service`, backed by a nosql datasource.

Standalone — no federation directives, no dependency on apps/gateway.

## Local DB setup

Needs a MongoDB instance reachable at `MONGO_URL` (defaults to `mongodb://localhost:27017`).

## Structure

Resolvers (`graphql/resolvers/`) stay thin: they validate input via
`validation/` (schemas from `libs/shared-validation`) before delegating to
`services/`, which owns business logic and datasource calls
(`datasources/nosql/`).

`nx serve internal-reporting-service`
